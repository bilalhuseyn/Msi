OBI Pro — Decision Making Architecture

Complete signal-to-trade pipeline with all approved changes (P1–P15)

Stage 1
Data Ingestion
Tardis.dev — OB Depth (book_snapshot_25) + Trades Binance — Klines 15min + 4h (for Market Structure) Deribit — Options Chain + DVOL (for GEX regime)
Order Book Feed
25-level bid/ask depth, real-time snapshots
→ bids[], asks[], mid_price, spread
Trade Feed
Matched trades with volume + aggressor side
→ trades[], buy_vol, sell_vol
Kline Feed
15min + 4h OHLCV candles from Binance
→ candles_15m[], candles_4h[]
Options Feed
Deribit options chain + DVOL for gamma regime
→ options_chain[], dvol, gex
Stage 2
Signal Modules (Independent, Parallel Processing)
M1 — OBI
Order Book Imbalance — bid/ask volume ratio, MA-smoothed
→ continuous float [-1.0, +1.0] (P6 fix)
M2 — VPIN
Volume-Sync Probability of Informed Trading
→ vpin_value (0-1), dynamic bucket (P2 fix)
M3 — Spread Monitor
MM engagement level — confidence multiplier (not directional)
→ multiplier: 1.0 / 0.7 / 0.3 / VETO (P4 fix)
M4 — Depth Erosion
Bid/ask depth change over time window
→ score {-1, 0, +1}
M5 — Spoofing Detector
Large order cancellation detection (live only, backtest = 0)
→ score {-1, 0, +1} (P11: 0 in backtest)
M6 — Clearance Detector
All 4 traces required + raised thresholds
→ ACTIVE (4/4) / POSSIBLE (3/4) (P8 fix)
M7 — Options Layer
GEX regime from Deribit data / DVOL proxy
→ regime, multiplier (P5 fix: real data)
PA Filter
EMA crossover, candlestick patterns — indicator-only
→ NOT CALLED (replaced by Market Structure)
Stage 3
VETO Gate — Entry Blocker Only (P1 Fix)
KEY RULE: VETO only blocks NEW position entries. It NEVER touches open positions. Open positions are managed by Stop Loss and Signal Module output only.
Veto Check Logic
if VPIN > 0.90 AND sustained for N ticks → BLOCK new entries (with confirmation)
if Spread = MM_WITHDRAWN → BLOCK new entries
if Clearance = ACTIVE (4/4 traces) → BLOCK new entries
else → PASS (proceed to CE)

No force_close_all(). Existing positions untouched. SL is the safety net.
Stage 4
Confirmation Engine (CE) — Weighted Score Aggregation
Weighted Score Calculation
score =
  OBI_continuous × 0.26
  + Depth × 0.26
  + Clearance × 0.24
  + Options × 0.24

(Spoof = 0 in backtest, weight redistributed)
(Spread removed from score — now multiplier)
Modifiers Applied
1. Spread multiplier: score × spread_mult
   MM_ACTIVE → ×1.0
   MM_CAUTIOUS → ×0.7
   MM_THINNING → ×0.3

2. Options regime: score × regime_mult
   LONG_GAMMA → ×0.85
   NEUTRAL → ×1.0
   SHORT_GAMMA → ×1.20
CE Output
if final_score ≥ threshold → LONG signal
if final_score ≤ -threshold → SHORT signal
else → NEUTRAL (no action)
Stage 5 — Final Gate
Market Structure Reader (Replaces PA Filter)
Swing Point Detection
Fractal pivots — swing highs and swing lows identification
→ swing_highs[], swing_lows[]
BOS Detection
Break of Structure — trend continuation confirmed
→ bullish_bos / bearish_bos
CHoCH Detection
Change of Character — trend reversal early warning
→ bullish_choch / bearish_choch
Trend Classification
HH/HL = bullish, LH/LL = bearish, else = range
→ BULLISH / BEARISH / RANGE
Multi-timeframe: Analyzes both 15min and 4h candles simultaneously. Uses Binance kline data (free, no API key required).
Structure Gate Logic
if CE = LONG AND structure = BULLISH or RANGE → ALLOW
if CE = LONG AND structure = BEARISH → BLOCK (counter-trend)
if CE = SHORT AND structure = BEARISH or RANGE → ALLOW
if CE = SHORT AND structure = BULLISH → BLOCK (counter-trend)
Stage 6
Position Execution & Management
Take Profit
TP1: 50% @ 2.0R (maker order)
TP2: 30% @ S/R level (Market Structure)
TP3: 20% trailing stop (ATR-based)
Stop Loss
ATR-based from 15min candles
min_stop = 0.5% of price
Primary safety net (not VETO)
Signal Exit
Signal Modules flip direction →
close existing position
Only way to force-close
Position rules: Maker orders (0.02% fee) preferred over taker (0.10%). Cooldown between trades. Daily trade cap enforced. Quality > quantity.

Full Signal Flow Summary
